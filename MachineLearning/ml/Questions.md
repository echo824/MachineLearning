# 学习疑问与思考

## 深度学习

### 1. 为什么 ReLU 函数只比线性函数多了一个非负就能在神经网络中起作用？

**疑问：** ReLU 只是 $\max(0, z)$，看起来和线性函数几乎一样，为什么能带来这么大的提升？

**解答：**

核心不在于"非负"，而在于**非线性**。

- **纯线性函数的问题**：无论堆叠多少层，多个线性函数的复合仍然是线性函数，深层网络等价于单层，层数毫无意义。
- **ReLU 的非线性来源**：在 $z = 0$ 处有一个"折点"，使得函数不再是全局线性的。多层 ReLU 的复合可以产生分段线性的复杂变换，从而逼近任意函数。
- **直观理解**：每一层 ReLU 都在"折叠"输入空间，多层叠加后通过反复折叠 + 旋转 + 缩放，将线性不可分的数据逐步变为可分。

**ReLU 相比 Sigmoid 的优势：**

| 特性 | ReLU | Sigmoid |
|------|------|---------|
| 计算效率 | 一次比较，极快 | 指数运算，较慢 |
| 梯度传播 | 正区间梯度恒为 1，不衰减 | 两端饱和，梯度趋近于 0 |
| 稀疏性 | 负值输出为 0，天然稀疏 | 所有神经元都有输出 |
| 深层训练 | 大幅缓解梯度消失 | 深层网络中梯度消失严重 |

**结论：** ReLU 的"折点"赋予了网络非线性表达能力，多层 ReLU 复合可以逼近任意复杂函数（万能逼近定理），而纯线性复合永远只能是线性变换。
