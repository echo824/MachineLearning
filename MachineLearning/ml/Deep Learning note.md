# 深度学习（Deep Learning）

## 神经网络（Neural Networks）

### 基本概念

神经网络是一种受生物神经系统启发的机器学习模型，由大量互联的人工神经元（节点）组成，用于学习数据中的复杂模式。

### 网络结构

- **输入层（Input Layer）**：接收原始特征数据，节点数等于特征维度
- **隐藏层（Hidden Layer）**：进行特征变换和非线性映射，可以有多个隐藏层
- **输出层（Output Layer）**：产生最终预测结果

**术语：**
- **神经元（Neuron）**：网络中的基本计算单元
- **权重（Weight）**：连接的强度参数，决定信号传递的重要性
- **偏置（Bias）**：每个神经元的附加参数，调整激活阈值
- **层数（Depth）**：隐藏层的数量，层数越多网络越"深"

### 前向传播算法（Forward Propagation）

从输入层到输出层逐层计算每个神经元的激活值，最终得到预测结果。

**单个神经元的计算：**

$$z = w^T x + b = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b$$

$$a = g(z)$$

其中：
- $z$：加权求和结果
- $w$：权重向量
- $x$：输入向量
- $b$：偏置
- $g(z)$：激活函数
- $a$：神经元的输出（激活值）

**多层网络的矩阵表示：**

$$Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}$$

$$A^{[l]} = g^{[l]}(Z^{[l]})$$

其中：
- $l$：第 $l$ 层
- $W^{[l]}$：第 $l$ 层的权重矩阵
- $A^{[l]}$：第 $l$ 层的激活值矩阵
- $A^{[0]} = X$：输入数据

### 激活函数（Activation Functions）

激活函数引入非线性，使神经网络能够学习复杂的模式。

#### 常见激活函数

**1. Sigmoid 函数**

$$g(z) = \frac{1}{1 + e^{-z}}$$

- 输出范围：$(0, 1)$
- 优点：输出可解释为概率，适合二分类输出层
- 缺点：梯度消失问题，输出非零中心化

**2. Tanh 函数**

$$g(z) = \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$$

- 输出范围：$(-1, 1)$
- 优点：零中心化，收敛通常比 Sigmoid 快
- 缺点：仍有梯度消失问题

**3. ReLU（Rectified Linear Unit）**

$$g(z) = \max(0, z)$$

- 输出范围：$[0, +\infty)$
- 优点：计算简单，缓解梯度消失，训练速度快
- 缺点：神经元死亡问题（Dead ReLU）

**4. Leaky ReLU**

$$g(z) = \begin{cases} z & \text{if } z > 0 \\ \alpha z & \text{if } z \leq 0 \end{cases}$$

- 通常 $\alpha = 0.01$
- 优点：解决 ReLU 的神经元死亡问题

**5. Softmax 函数**（多分类输出层）

$$g(z)_k = \frac{e^{z_k}}{\sum_{i=1}^{K} e^{z_i}}$$

- 输出范围：$(0, 1)$，且所有输出之和为 1
- 用途：多分类问题的输出层，输出各类别的概率

#### 激活函数选择指南

| 场景 | 推荐激活函数 |
|------|--------------|
| 隐藏层（通用） | ReLU |
| 隐藏层（需要零中心化） | Tanh |
| 二分类输出层 | Sigmoid |
| 多分类输出层 | Softmax |
| 回归任务输出层 | 线性函数（无激活） |

**经验法则：**
- 默认从 ReLU 开始尝试
- 如果遇到神经元死亡问题，改用 Leaky ReLU
- 输出层根据任务类型选择（二分类用 Sigmoid，多分类用 Softmax）

### 成本函数（Cost Function）

**二分类（Binary Cross-Entropy）：**

$$J = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log \hat{y}^{(i)} + (1 - y^{(i)}) \log \left(1 - \hat{y}^{(i)}\right) \right]$$

**多分类（Categorical Cross-Entropy）：**

$$J = -\frac{1}{m} \sum_{i=1}^{m} \sum_{k=1}^{K} y_k^{(i)} \log \hat{y}_k^{(i)}$$

**回归（MSE）：**

$$J = \frac{1}{2m} \sum_{i=1}^{m} \left( \hat{y}^{(i)} - y^{(i)} \right)^2$$

### 反向传播算法（Backpropagation）

通过链式法则计算损失函数对每个参数的梯度，从输出层向输入层逐层传播。

**核心思想：**

$$\frac{\partial J}{\partial W^{[l]}} = \frac{\partial J}{\partial Z^{[l]}} \cdot \frac{\partial Z^{[l]}}{\partial W^{[l]}}$$

**参数更新：**

$$W^{[l]} := W^{[l]} - \alpha \frac{\partial J}{\partial W^{[l]}}$$

$$b^{[l]} := b^{[l]} - \alpha \frac{\partial J}{\partial b^{[l]}}$$

## 常见深度学习架构

### 卷积神经网络（CNN）

主要用于图像处理和计算机视觉任务。

**核心组件：**
- **卷积层（Convolutional Layer）**：提取局部特征（边缘、纹理等）
- **池化层（Pooling Layer）**：降低特征图维度，增强平移不变性
- **全连接层（Fully Connected Layer）**：进行分类或回归

**典型应用：** 图像分类、目标检测、语义分割

#### 经典 CNN 架构演进

| 网络 | 年份 | 关键创新 |
|------|------|----------|
| **LeNet-5** | 1998 | 第一个成功的 CNN，用于手写数字识别 |
| **AlexNet** | 2012 | 深度学习的引爆点，使用 ReLU + Dropout + GPU 训练 |
| **VGG** | 2014 | 用连续的 3×3 卷积替代大卷积核，更深更简洁 |
| **GoogLeNet** | 2014 | Inception 模块，多尺度特征并行提取 |
| **ResNet** | 2015 | **残差连接（Skip Connection）**，解决深层网络退化问题，训练出 152 层网络 |

**残差连接（Residual Connection）：**

$$y = F(x) + x$$

- 允许梯度直接跳过某层传播，解决梯度消失问题
- 使网络可以训到极深（1000+ 层）而不退化
- 几乎所有现代架构都采用了残差连接

### 循环神经网络（RNN）

主要用于序列数据处理（时间序列、自然语言）。

**核心特点：** 具有记忆能力，当前输出依赖于当前输入和历史状态

**变体：**
- **LSTM（Long Short-Term Memory）**：解决长序列梯度消失问题
- **GRU（Gated Recurrent Unit）**：LSTM 的简化版本，参数更少

**典型应用：** 机器翻译、语音识别、时间序列预测

### Transformer

基于自注意力机制的架构，完全摒弃了循环结构。

**核心组件：**
- **自注意力机制（Self-Attention）**：计算序列中每个位置与其他位置的相关性
- **多头注意力（Multi-Head Attention）**：并行执行多个注意力机制
- **位置编码（Positional Encoding）**：注入序列位置信息

**典型应用：** 大语言模型（GPT、BERT）、机器翻译、图像生成

## 训练技巧与优化

### 常见优化算法

- **SGD（随机梯度下降）**：每次用一个 mini-batch 更新参数
- **Momentum**：引入动量项，加速收敛
- **Adam**：自适应学习率，结合 Momentum 和 RMSProp 的优点

### 正则化技术

- **Dropout**：训练时随机丢弃部分神经元，防止过拟合
- **L2 正则化（权重衰减）**：惩罚过大的权重值
- **Batch Normalization**：标准化每层的输入，加速训练
- **Early Stopping**：验证集性能不再提升时停止训练

### 超参数调优

- **学习率**：最重要的超参数，通常从 0.001 开始尝试
- **Batch Size**：常见值 32、64、128、256
- **网络结构**：层数、每层神经元数量
- **正则化参数**：Dropout 比例、L2 系数

### 迁移学习（Transfer Learning）

将在大规模数据集上预训练的模型迁移到目标任务上进行微调，避免从零训练。

**核心思想：** 低层特征（边缘、纹理）具有通用性，高层特征与具体任务相关。

**常见策略：**

| 策略 | 做法 | 适用场景 |
|------|------|----------|
| **特征提取** | 冻结预训练模型，只训练分类头 | 数据量少，任务相似 |
| **微调（Fine-tuning）** | 解冻部分或全部层，用小学习率训练 | 数据量中等，任务有一定差异 |
| **全层微调** | 所有层都参与训练 | 数据量大，任务差异较大 |

**实践要点：**

- 冻结的层越多，所需数据量越少
- 微调时使用较小的学习率（如 $10^{-5}$），避免破坏已学到的特征
- 常用预训练模型：ImageNet 预训练的 ResNet、VGG 等

### 生成对抗网络（GAN）

由生成器和判别器组成的博弈框架，用于生成逼真的数据。

**核心架构：**

- **生成器（Generator）**：从随机噪声生成假数据，目标是“骗过”判别器
- **判别器（Discriminator）**：区分真实数据和生成数据，目标是“识破”假数据

**目标函数：**

$$\min_G \max_D \; \mathbb{E}_{x \sim p_{\text{data}}} [\log D(x)] + \mathbb{E}_{z \sim p_z} [\log(1 - D(G(z)))]$$

**训练过程：**

1. 固定 G，训练 D：让 D 学会区分真假
2. 固定 D，训练 G：让 G 生成更逼真的数据
3. 交替训练，最终达到纳什均衡

**常见变体：**

| 变体 | 特点 |
|------|------|
| **DCGAN** | 使用卷积结构，训练更稳定 |
| **WGAN** | 用 Wasserstein 距离替代 JS 散度，解决训练不稳定 |
| **StyleGAN** | 引入风格控制，生成极高质量的人脸图像 |
| **CycleGAN** | 无需配对数据，实现图像风格转换 |

**典型应用：** 图像生成、风格迁移、图像超分辨率、数据增强

### Deep Q-Network（DQN）

将深度学习与强化学习结合，用神经网络近似 Q 函数，解决高维状态空间下的决策问题。

**核心思想：**

$$Q(s, a; \theta) \approx Q^*(s, a)$$

**关键创新：**
- **经验回放（Experience Replay）**：存储并随机采样历史转移，打破数据相关性
- **目标网络（Target Network）**：使用独立的目标网络计算 TD 目标，稳定训练

**损失函数：**

$$L(\theta) = \mathbb{E} \left[ \left( r + \gamma \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta) \right)^2 \right]$$

其中 $\theta^-$ 是目标网络参数（定期从 $\theta$ 复制）。

**典型应用：**

| 场景 | 说明 |
|------|------|
| **Atari 游戏** | DQN 直接从像素学习玩游戏，超越人类水平 |
| **围棋 AI** | AlphaGo 结合 MCTS + 深度 RL（策略网络 + 价值网络） |
| **机器人控制** | 通过试错学习复杂运动技能 |
| **推荐系统** | 将用户交互建模为 MDP，优化长期收益 |
